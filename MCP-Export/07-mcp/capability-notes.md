# CLAD and SPECS Experience Builder capabilities

This session exposes the Lens Studio MCP toolset directly. The project-related skill toolkit available to the agent includes the router, scene construction, editor API, Specs project setup, preview inspection, Specs UI, package install/update, LEAF test authoring/running, Specs interaction, camera/depth/world query, sync, networking, audio, publishing, debug, and optimization skills. Available skills are workflow guidance; they do not imply those operations were invoked.

See the categorized tool inventory JSON files for the actual MCP tool names, descriptions, and input schema text surfaced in this session. Tools discovered include read and query surfaces, scene/asset mutation surfaces, compilation/test surfaces, and package management.
